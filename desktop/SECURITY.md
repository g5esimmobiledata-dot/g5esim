# Security Policy

## Supported Project Scope

This repository contains only the public Electron desktop wrapper for G5eSIM.

The private G5eSIM backend, provider integrations, customer records, payment configuration, and production credentials are outside the scope of this repository.

## Reporting a Vulnerability

Please report security issues privately by email:

security@g5esim.mobile

Include:

- A short summary
- Reproduction steps
- Affected version or commit
- Any relevant logs or screenshots

Please do not open a public issue for vulnerabilities that could affect users.
