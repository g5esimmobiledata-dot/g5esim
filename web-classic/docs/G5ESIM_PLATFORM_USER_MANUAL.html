1. Platform Overview

G5ESIM is a telecom and digital-services platform for selling and managing eSIM packages, eRoaming DID numbers, SIP services, IPTV subscriptions, wallets, vouchers, gift cards, support, chat, and reseller or agent operations.

Admin Backend

Full control of customers, resellers, agents, providers, modules, pricing, billing, reports, languages, security, and platform content.

Reseller

Business workspace for managing own customers, agents, prices, storefront, wallet, vouchers, orders, support, and enabled modules.

Agent

Sales and support workspace for assigned customers. Agent access depends on modules enabled by Admin or Reseller.

User

Customer area and mobile app access for buying, using, and managing services.

Important: Module permission decides whether a role can see or use a feature. Billing/profile rules decide whether that feature is free, paid, trial-based, web-enabled, or mobile-enabled.

2. Admin Backend Basics

How to Login as Admin

  1. Open the Admin Panel URL.
  2. Enter the admin email/username and password.
  3. If 2FA is enabled, enter the authenticator code.
  4. After login, review the dashboard, alerts, pending orders, and support tickets.

Daily Admin Checklist

  • Check failed or pending orders.
  • Check support tickets and VIP Concierge requests.
  • Check payment gateway and wallet activity.
  • Check provider sync status for eSIM, DID, SIP, and IPTV services.
  • Review suspicious login/IP activity.

3. How Admin Creates Users, Agents, and Resellers

Simple meaning: this is where Admin adds a new customer, agent, or reseller, then decides what that account can use.

Create a New User

  1. Go to Admin Panel > Customers > User.
  2. Click Create or New User.
  3. Enter the customer name, email, phone number, password, account status, and account type.
  4. Select which modules/features the user can access if the form provides module controls.
  5. Save the user.
  6. Open the user details page and confirm wallet, KYC, modules, orders, and status.

Create a New Agent

  1. Go to Admin Panel > Customers > Agent.
  2. Create the account and set account type as Agent.
  3. Assign permissions/modules such as customers, orders, wallet, eSIM packages, eRoaming, IPTV, vouchers, invoices, support, and platform setup if required.
  4. If the agent belongs under a reseller, assign the correct parent reseller.
  5. Save and test login as the agent.

Create a New Reseller

  1. Go to Admin Panel > Customers > Reseller.
  2. Create the reseller account with name, email, phone, password, and active status.
  3. Enable reseller modules such as storefront, payment gateways, currencies, modules, API docs, customers, eSIM pricing, eRoaming, IPTV, wallet, vouchers, invoices, and support.
  4. Configure reseller pricing and wallet rules if needed.
  5. Save and test the reseller dashboard.
Security: Do not enable reseller or agent permissions unless the account is trusted. Always confirm KYC or business verification when required.

4. How to Top Up Funds and Manage Wallets

Simple meaning: wallet is the customer balance. Users can add money by payment gateway or voucher. Admin can manually adjust it when needed.

User Wallet Top Up

  1. User opens Account > Wallet.
  2. User selects wallet top-up amount.
  3. User pays using an enabled payment gateway or redeems a voucher if available.
  4. After successful payment, wallet balance is updated.
  5. User can use wallet balance to buy supported services.

Admin Manual Wallet Adjustment

  1. Go to Admin Panel > Customers.
  2. Open the customer details page.
  3. Find the wallet/balance section.
  4. Add or deduct balance with a clear reason.
  5. Save and confirm the transaction appears in wallet history.

Voucher Wallet Top Up

  1. Admin or permitted reseller creates voucher batch under Vouchers.
  2. Set voucher type as wallet credit, amount, quantity, status, and validity.
  3. User opens wallet or voucher page and redeems the code.
  4. The value is credited to wallet after successful redemption.
Audit rule: Every manual wallet action should include a reason so finance and support can understand why funds changed.

5. How to Enable Features and Modules

Simple meaning: modules are ON/OFF switches. If a module is OFF, the user cannot see or use that service.

Enable Modules Globally by Role

  1. Go to Admin Panel > Platform Setup > Modules or Features.
  2. Select the role: User, Agent, or Reseller.
  3. Enable or disable modules for web access.
  4. Enable or disable modules for mobile app access where available.
  5. Save changes.
  6. Login with a test account for that role and confirm the menu changed correctly.

Enable Modules for One Specific Customer

  1. Go to Admin Panel > Customers.
  2. Open the specific user, reseller, or agent.
  3. Open the Modules or Features section.
  4. Turn on the services that this account can use.
  5. Save and confirm from the customer account.

6. eSIM Services

Simple meaning: eSIM service lets customers buy mobile data for a country or region, then install it using QR/manual details.

What the eSIM Module Does

The eSIM module lets users browse destinations, buy data packages, view installation details, and manage purchased eSIMs. Admin controls providers, package catalog, rates, countries, regions, top-ups, and package visibility.

Admin: Configure eSIM Services

  1. Go to Admin Panel > Master eSIM Packages > Providers.
  2. Add or configure provider API credentials.
  3. Sync packages from providers.
  4. Go to eSIM Catalog and enable packages that should be visible.
  5. Configure Rates, markup, and selling prices.
  6. Check Countries and Regions.
  7. Test a purchase using a user account.

User: Buy an eSIM

  1. Open the website or mobile app.
  2. Search for the destination country or region.
  3. Select the package by data amount, validity, and price.
  4. Pay by card, wallet, voucher, or another enabled method.
  5. Open My eSIMs to view QR code and installation instructions.
Customer warning: eSIM QR codes are usually single-use. The customer must install it on the correct unlocked eSIM-compatible device.

7. eSIM Top-Up Packages

What Top-Up Does

Top-up packages allow users to add more data or validity to an existing eligible eSIM without buying a new eSIM profile.

Admin: Manage Top-Ups

  1. Go to Admin Panel > Master eSIM Packages > Topup Packages.
  2. Sync top-up packages from enabled providers.
  3. Check which base packages support top-up.
  4. Set cost and selling prices where needed.
  5. Review top-up orders under Order Management > Top-up Orders.

User: Buy Top-Up

  1. Open My eSIMs.
  2. Select an eSIM that supports top-up.
  3. Select top-up package.
  4. Pay and wait for confirmation.

8. eRoaming and DID Numbers

What eRoaming Does

eRoaming lets users buy and use DID/virtual numbers. A DID can receive calls and can also be connected to SIP services depending on configuration.

Admin: Configure DID Services

  1. Go to Admin Panel > eRoaming's > Providers.
  2. Configure DID provider credentials and settings.
  3. Go to DID Numbers to import, sync, or manage available numbers.
  4. Set pricing under Cost & Price.
  5. Review purchases under Logs & Purchase, Pending, and Active.

User: Buy or Use DID

  1. Open Account > eRoaming's or the mobile app eRoaming area.
  2. Select country and number if available.
  3. Review setup fee, monthly fee, and terms.
  4. Pay using available payment method.
  5. After activation, view the DID under My DID's.
Billing rule: DID registration profile fees are extra fees only. If DID is marked Free in a profile, no extra profile charge is added on top of the normal DID price.

9. SIP Users, Tariffs, and Registration Profiles

Simple meaning: SIP is the calling account. It controls internal calls, international calls, DID receiving, voicemail, PBX, recording, and call rules.

What SIP Does

SIP services allow users to make internal SIP-to-SIP calls, international outgoing calls, receive calls through assigned DID numbers, and use telephony features such as voicemail, call recording, forwarding, ring groups, caller ID, and PBX functions.

Admin: Create SIP User

  1. Go to Admin Panel > Extra > eRoaming SIP Users.
  2. Click Create SIP User.
  3. Select Create User: New or Existing.
  4. If New, choose Auto Generate or Manual SIP username/password.
  5. If Existing, select the platform user and enter or select SIP details.
  6. Select SIP Provider. Provider details fill automatically where configured.
  7. Select Registration Profile.
  8. Assign Internal Tariff and International Tariff.
  9. Allocate DID number if the user needs inbound calls.
  10. Enable or disable features such as internal calls, international calls, voicemail, PBX, chat, call recording, fax, and other modules.
  11. Save and test the SIP user.

Admin: Configure SIP Tariffs

  1. Go to SIP Configuration > Tariff's.
  2. Use Internal for internal SIP destinations.
  3. Use Origination Rates for international outgoing call rates.
  4. Create a Tariff Name, then open it to manage destinations and prefixes.
  5. Use Import/Export for bulk origination destinations.
  6. Use Rate Group to assign provider, routing type, reseller/agent/user ownership, and routing behavior.

Admin: Registration Profile

  1. Go to SIP Configuration > Registration Profile.
  2. Create a profile for automatic signup or manual registration.
  3. For each feature, choose Enabled/Disabled.
  4. Choose Free or Paid.
  5. If Paid, set setup fee, monthly fee, fixed charge, charge percentage, and free trial days if allowed.
  6. Choose whether each feature is enabled for Web users and Mobile App users.
Important: Paid feature fees in the registration profile are extra charges. They should not replace the normal DID, SIP, eSIM, or other base service price.

10. Chat, Media, Voice, and Video Features

Simple meaning: chat is the built-in WhatsApp-style module for messages, media, voice/video calls, recordings, and quick media access.

What Chat Does

Chat allows platform users to communicate with other users from web or mobile, share media, send voice/video messages, and start voice/video calls where real-time calling is configured.

Main Chat Features

  • Direct chat, group chat, and broadcast.
  • Photo, video, document, contact, location, poll, event, fax, screenshot, app share, and AI image request cards.
  • Voice messages and video messages.
  • Voice call, video call, group call.
  • Call recording and saved call recordings inside the chat session.
  • Quick access filters for images, videos, all media, and call recordings.
  • Download and forward media or recordings.

How User Starts a Chat

  1. Open Account > Chat or mobile chat.
  2. Search by phone, email, SIP username, or UID.
  3. The user list stays hidden until at least 3 characters or 3 digits are entered.
  4. Select the contact and start chat.

Admin Setup Notes

  • Enable Chat module for the role or specific user.
  • Enable Chat in SIP registration profile if SIP-related chat permissions are required.
  • For reliable voice/video calls behind firewalls or blocked networks, configure TURN relay service on 443/TLS.

12. Payments, Gateways, Vouchers, and Gift Cards

Payment Gateways

  1. Go to Admin Panel > Payment Gateways > Gateways.
  2. Enable the gateway.
  3. Enter API keys, secret keys, webhook settings, and mode.
  4. Save and run a test checkout.

Vouchers

Vouchers can be used for wallet credit, promotions, reseller credits, or controlled customer balance top-ups.

  1. Go to Marketing > Vouchers.
  2. Create voucher code or batch.
  3. Select value, quantity, validity, status, and usage rules.
  4. Share voucher codes with users or resellers.

Gift Cards

13. KYC, Support, Concierge, and Security

KYC Verification

KYC verifies user identity and can be required before high-risk services are used.

  1. User opens KYC Verification.
  2. User uploads required documents.
  3. Admin reviews documents under Customers > KYC Verification.
  4. Admin approves or rejects.

Support Tickets

  1. User opens support/VIP Concierge.
  2. User submits message and attachments.
  3. Admin replies from Support System.
  4. Ticket is closed after resolution.

Security

  • Use 2FA for Admin, Reseller, and Agent accounts.
  • Review IP logs for suspicious activity.
  • Do not share SIP, provider, payment, or API credentials with users.
  • Disable accounts immediately if compromise is suspected.

14. Reseller Guide

Simple meaning: reseller is a business account that can sell services to its own customers under the permissions Admin gives.

What Reseller Can Do

A reseller manages their own customers and business workspace. Access depends on modules enabled by Admin.

Common Reseller Actions

  1. Login to the reseller panel.
  2. Check dashboard, statistics, wallet, and recent orders.
  3. Create or manage customers and agents if allowed.
  4. Set eSIM cost and selling prices if allowed.
  5. Manage eRoaming/DID and IPTV users if modules are enabled.
  6. Create vouchers if enabled.

  8. Configure storefront, SMTP, currencies, payment gateways, pages, FAQ, blog, language, and translations if platform setup is enabled.

15. Agent Guide

Simple meaning: agent is a sales/support account that helps assigned customers but should not have full reseller or admin access.

What Agent Can Do

An agent helps sell and support services for assigned customers. Agent access is controlled by Admin or Reseller permissions.

Common Agent Actions

  1. Login to the agent/account workspace.
  2. Check assigned customers.
  3. Create or help customers if allowed.
  4. Place eSIM, eRoaming, IPTV, or other service orders if enabled.
  5. Use wallet, vouchers, invoices, and support tools if enabled.
  6. Escalate unresolved problems to Reseller or Admin.
Rule: Agents should only see the modules and customers assigned to them.

17. Mobile App Guide

Simple meaning: the mobile app gives the customer the same important services in a phone-friendly interface.

What the Mobile App Does

The mobile app lets customers use core services from Android or iOS. Available features depend on enabled mobile modules.

Mobile Features

  • Register and login.
  • Switch languages such as English, Arabic, French, Spanish, Italian, and Russian where translations are available.
  • Buy and view eSIM packages.
  • View orders and wallet.
  • Use eRoaming/DID and SIP dialpad where enabled.
  • Make internal SIP or international calls where allowed.
  • Use chat, voice messages, video messages, media sharing, voice calls, video calls, and recordings where enabled.
  • Submit KYC and support requests.

Mobile SIP Calling Rules

  • Internal SIP calls should allow internal SIP usernames without international format.
  • International calls should require a country code.
  • Call history should show previous calls.
  • Speaker, dial tone, and call audio require the mobile voice engine and correct app rebuild, not only hot reload.

18. Troubleshooting and Support Checklist

When a User Cannot See a Feature

  1. Check account status is active.
  2. Check KYC status if required.
  3. Check global module setting for that role.
  4. Check user-specific module overrides.
  5. Check web/mobile access for that feature.
  6. Check registration profile billing if SIP/eRoaming feature.

When Wallet Top Up Fails

  1. Check payment gateway status.
  2. Check transaction logs.
  3. Check webhook delivery.
  4. Check if wallet top-up module is enabled.
  5. Check if manual credit is needed after payment confirmation.

When eSIM Order Fails

  1. Check payment status.
  2. Check provider response.
  3. Check package availability.
  4. Check customer email and account status.
  5. Retry provider sync or create support escalation.

When Voice/Video Chat Call Has No Audio

  1. Check microphone/camera browser permissions.
  2. Check device audio output.
  3. Check whether HTTPS is used.
  4. Check TURN server configuration for blocked networks.
  5. Check that both users accepted the call.
