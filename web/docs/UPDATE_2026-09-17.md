# September 17, 2026 web update

The web source already includes dedicated customer creation routes for users,
agents, and resellers in both `client/src/App.tsx` and
`client/src/components/admin/AdminShell.tsx`. Each `/create` route precedes its
`/:customerId` route and renders `CustomerManagement` in `createMode`, so the
word `create` is not treated as a customer ID. These routes were checked against
the corresponding September 17 production fix.

The production page-load improvement was an Nginx configuration change.
`deployment/nginx-assets.conf` preserves that change: JavaScript, CSS, JSON,
and SVG public assets are compressed before transfer. Include the snippet
inside your existing HTTPS server block, replacing any existing
`location /assets/` block. Run `nginx -t` before reloading Nginx. Local Vite
development does not require Nginx.

This update preserves the existing web source and its newer local features;
it does not replace it wholesale with the separately maintained production
server tree. No mobile source, mobile configuration, or mobile lockfiles are
changed by this update. Production credentials, databases, and uploads remain
outside Git.

## Update an existing macOS checkout

From the repository root, first commit your local macOS work (including mobile
changes) on your working branch. Then fetch and merge the published web update:

```sh
git fetch origin
git merge origin/main
cd web
npm ci
npm run build
```

Keep your existing private `.env` and Firebase configuration. For a new checkout,
follow `MACOS_SETUP.md` at the repository root. Start local development with
`npm run dev` after configuring your local database as described there.
