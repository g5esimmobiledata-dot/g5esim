Install G5 eSIM on Android

Open this page in Chrome or Edge on Android, then use the install button to add G5 eSIM to the home screen as a PWA.

Open PWA Download APK
  1. 1 Scan the QR code with the Android camera.
  2. 2 Open the link in Chrome or Edge.
  3. 3 Tap Install PWA. If the button is not ready, use the browser menu and choose Add to Home screen or Install app.
  4. 4 Confirm the install. G5 eSIM will appear as an app icon.
